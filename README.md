# 🃏 斗地主 · 学一学，玩一玩

一个**专为长辈设计**的斗地主教学 + 单机对战网站：字大、按钮大、节奏慢、有语音讲解，打开就能玩，看完就会。

> 纯静态站点，无构建步骤、无后端、无外链图片，所有牌面打包在本地，国内也能秒开。可直接用 GitHub Pages 部署。

---

## ✨ 功能特色

### 📖 教学区（8 课循序渐进）
- 认识扑克牌 → 认识角色 → 叫分选地主 → 认识牌型 → 怎么出牌 → 输赢算分 → 实战技巧 → **两副牌玩法**
- 每课配**口诀、牌例图、情景问答**，一键**朗读**整课
- **牌型图鉴**：13 种牌型全收录，想不起来随时翻
- **小测验**：大按钮选择，答错有温和讲解，不打击信心
- **引导式模拟小游戏**：上桌一步步教「遇到这种情况怎么出」，点错可重试

### 🂠 游戏区
- **标准对局**：两个 AI 陪打，右下角常驻「❓ 教我」提示按钮，拿不准随时点
- **练习模式**：每一手都讲解「为什么这么出」，学完再实战
- **两副牌玩法**：108 张，每人 34 张 + 6 底牌；**炸弹 4～8 张**、**张数多者大**、**王炸 = 双小王 + 双大王**
- 54 张高清牌面全部打包本地，零外链

### 🛠 针对长辈打磨
- **慢节奏**：AI 出手刻意放慢，看得清再反应；语音排队播报，不抢话
- **手牌动态自适应**：任意屏宽、任意牌数、任意字号都不超屏；**伞状扇形手牌 + 选中放大**
- **触屏 + 鼠标双支持**：按下即时放大、滑动防误触、选中牌整体让开
- 底牌移到屏幕最顶端；上下家出的牌同时在桌面显示
- 矮屏 / 窄屏一体化布局，手牌永远可见可点
- 字号、语音、难度都可调；学习进度自动记录

## 🚀 快速开始

项目是**纯静态站点**，不需要安装任何依赖：

1. 下载 / 克隆本仓库
2. 双击打开 `index.html`，或运行本地静态服务器：

```bash
# 任选其一
python3 -m http.server 8080
# 或
npx serve .
```

3. 浏览器访问 `http://localhost:8080` 即可

> 也支持一键部署到 **GitHub Pages**（仓库 Settings → Pages → 选择 main 分支根目录）。

## 🧰 技术栈

原生 HTML / CSS / JavaScript，无框架、无构建步骤。

| 文件 | 职责 |
| --- | --- |
| `js/cards.js` | 牌型识别 / 比较 / 发牌（支持 1 副 / 2 副牌，`nDeck` 参数贯穿全链） |
| `js/game.js` | 对局状态机（叫分 → 出牌 → 结算） |
| `js/ai.js` | 电脑叫分与出牌 AI（多套候选 + 随机可变稳定策略） |
| `js/hint.js` | 提示引擎：当前局面该出什么 + 为什么 |
| `js/speak.js` | 中文语音播报（队列，不抢话） |
| `js/ui.js` | 牌面渲染、选中、动画 |
| `js/data.js` | 8 课文案、牌型图鉴、测验、模拟小游戏数据 |
| `js/learn.js` | 教学区渲染 |
| `js/sim.js` | 引导式模拟小游戏逻辑 |
| `js/storage.js` / `js/theme.js` | localStorage 持久化 / 主题字号 |

数据持久化使用 `localStorage`（统一前缀 `ddz_`）。

纯 Node 测试（无需浏览器），共 7 套：

```bash
node test_twodeck.js      # 两副牌玩法（40 项 + 150 局闭环）
node test_hand_layout.js  # 手牌布局仿真（5760 组合）
node test_spread.js       # 选中让开 + 露边压缩仿真（900 项）
node test_touch.js        # 触屏交互（6 项）
```
